# MatchLens — Yeni Oturum Başlangıcı

Claude Code bu klasörde açıldığında `CLAUDE.md` otomatik yüklenir: proje kuralları (`.agents/AGENTS.md`), devir notunu okuma talimatı ve Graphify kuralları oradadır. Bu yüzden uzun bir başlangıç prompt'u gerekmez, ne istediğini yazman yeterlidir.

Projenin güncel durumu ve sıradaki iş `docs/07_session_handoff.md` dosyasında, kararların geçmişi `docs/03_roadmap.md` dosyasındadır. Durum değiştikçe bu dosyalar güncellenir, buraya kopyalanmaz.

Claude Code dışında bir AI ile çalışırken şu iki dosyayı ve `.agents/AGENTS.md` dosyasını sohbete ekle.
